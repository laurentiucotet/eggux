# Nielsen's 10 usability heuristics: review questions

1. **Visibility of system status**
   Does the user always know what is happening? Loading, saving, progress, current location
   (active nav item, breadcrumbs), selection state.
2. **Match between system and the real world**
   Is the language the client's and the actor's (decisions.md terminology), not internal or
   technical? Do order and grouping follow how the actor thinks about the objects?
3. **User control and freedom**
   Cancel, back, undo, close. Can the user leave any flow without losing work?
4. **Consistency and standards**
   Same component, same meaning, everywhere. Platform conventions respected. Tokens and text
   styles used consistently.
5. **Error prevention**
   Confirmations for destructive actions, constrained inputs, sensible defaults, warnings
   before consequences.
6. **Recognition rather than recall**
   Options visible, labels always shown, recent items, context carried between steps.
7. **Flexibility and efficiency of use**
   Shortcuts, bulk actions, saved filters for frequent actors (check workflow frequency).
8. **Aesthetic and minimalist design**
   Every element earns its place. One primary action. Clear hierarchy via text styles.
9. **Help users recognize, diagnose and recover from errors**
   Plain-language errors next to the cause, with the fix. Input preserved.
10. **Help and documentation**
    Inline hints and empty states explain what to do; help is findable where it is needed.
