## Design findings
Differences between Figma, the references and code, found while building. Each needs a decision
in Figma or in the reference; code follows the column "Code".

| Component | Finding | Code |
|---|---|---|
| Skeleton Preset | List-row at min width 240: the second line (fixed 120) runs past its 88 px column under the trailing value | clamps with `max-w-full`; Figma should use Fill or a max width |
| Skeleton | Guide `build-ui/components/skeleton.md` says `background/muted`, the component uses `background/accent` | follows the component (accent) |
| Skeleton Preset | `code-mapping.md` sizes differ from Figma: stat value w-36 (Figma 140), list line w-32 (Figma 120), table-row as `TableRow` (Figma is a flex row), chart bars without radius (Figma radius-sm) | follows Figma; the mapping needs updating |
| Switch | Figma fades the whole disabled switch to 50 %, description included; faded description fails 4.5:1 | description stays full color, as in Radio |
| Switch | Figma description is one fixed line, the reference says 3 lines then ellipsis | 3-line clamp |
| Presence Bar | No idle state in Figma; at 50 % opacity initials fail contrast | idle at 70 % |
| Chip | Remove x target is 16 px, under the 24 px minimum (WCAG 2.5.8) | 16 px as in Figma; needs a larger hit area |
| Avatar Status | Away (amber) dot is under 3:1 on white | always paired with text |
| Toggle Group | Figma stress frame: a default group overflows its 50 % column (items never shrink) | same as Figma; only full-width segmented truncates |
| Date Input | The spacer before the calendar button is a fixed 1 px, so the button sits right after the year | spacer fills: button at the right end, as in Date Picker |
| Date Input | A focused empty segment with muted text on the accent fill is 4.35:1 | placeholder uses accent-foreground when focused |
| Signature Pad | No script font token for the typed name | `font-serif` italic until a token exists |
| Range / Duration / Date Input | Figma has no rule messages (min above max, over the limit, date rules) and no disabled state | message under the field in the Field error style; disabled through Field |
